Guide utilisateur OctoPIM

Retrouver un produit, le completer, l’importer ou l’exporter. Ce que vous pouvez faire depend de votre role.

Action impossible

Si vous ne pouvez pas modifier ou supprimer (bouton absent, enregistrement refuse, import bloque), vos droits ne le permettent pas. Contactez l’administrateur de la solution, Alexis Béranger. Ne contournez pas le droit.

Se connecter

Ouvrez OctoPIM et choisissez votre compte. Le menu et les produits visibles dependent de votre role. En cible, la connexion passera par Okta : OctoPIM ne gere pas le mot de passe.

Retrouver un produit

  • La liste ne montre que les categories que vous avez le droit de lire.
  • Utilisez la recherche, le filtre de categorie, le tri sur une colonne.
  • La vue Synthese reprend les colonnes definies pour tout le monde. La vue Detaillee montre les groupes de la categorie choisie. Sans categorie, ces groupes ne s’affichent pas.
  • Cliquez le nom pour ouvrir la fiche. Un picto signale un produit sous ou au-dessus d’un seuil.
  • Depuis le tableau de bord, une carte d’alerte ouvre la liste deja filtree sur ce seuil.
  • Le bouton Nouveau produit n’apparait que si vous pouvez ecrire au moins une categorie. EAN, nom et categorie sont obligatoires. Le code SAP peut rester vide.

Completer une fiche

  • Les onglets sont les groupes de la categorie du produit. Il n’y a pas d’onglet Synthese.
  • Les champs courts se rangent cote a cote. Un texte long ou une image prend toute la largeur.
  • Un champ avec un picto entre dans la completion. Sans picto, il est optionnel. Un champ a completer encore vide a un fond rose pale.
  • Miroir, Pola, Dégradé, teinte des verres et categorie du verre apparaissent des que la monture est solaire, juste apres Optique / Solaire.
  • La barre en haut de la fiche et la barre de chaque onglet se mettent a jour pendant la saisie.
  • Enregistrer refuse la fiche si un champ obligatoire est vide. L’historique n’est ecrit qu’a l’enregistrement.
  • Retour a la liste et Enregistrer restent visibles quand vous defilez. Quitter avec des changements non enregistres demande une confirmation.
  • Un champ jaune est calcule. Vous pouvez forcer une valeur, puis revenir au calcul.
  • Réassort automatique SAP passe à A désactiver quand actif canal O et actif canal L sont tous les deux Non. En attente ne compte pas comme Non. Sinon, la valeur choisie reste.
  • Sur un accessoire, le code SAP est le code article magasin. La désignation magasin, l’année de lancement, la matière, les dimensions et le conditionnement d’origine sont dans Caractéristiques accessoire. La couleur est la même que sur une monture. Les prix calculés de l’accessoire (PV TTC arrondi, PV HT, marge HT, taux) sont des champs à part de ceux de la monture.
  • Sur une lentille, la marque est dans Caractéristiques lentille. Lentilles et PEL partagent l’onglet Tarification lentilles + PEL : prix de vente TTC et prix de vente HT, avec deux décimales.
  • Les prix et les PA s’affichent avec deux decimales. Le PVMC et le PV TTC arrondi n’en ont pas. Un pourcentage s’affiche en %.
  • Le panneau Conditions commerciales montre le code fournisseur et le trigramme, avec le bareme de l’accord.
  • Si un seuil est depasse, la fiche l’indique sous le titre et sur le champ.

Importer

  • Choisissez ajout, modification ou suppression, puis la categorie et le fichier.
  • Chaque colonne se relie a un identifiant d’attribut. EAN, nom et categorie doivent etre presents pour un ajout ou une modification.
  • Un produit deja connu est reconnu d’abord par l’EAN, sinon par le SAP.
  • La suppression exige l’EAN ou le SAP, et le droit de supprimer.
  • Si l’import est refuse, c’est un droit ou un champ obligatoire : contactez Alexis Béranger si le droit vous manque.

Exporter

  • Le nombre de produits est celui du fichier. Une selection dans la liste le reduit. « Tout exporter » ignore la selection.
  • Catalogue, IWI ou une trame enregistree : cochez un groupe, depliez-le pour retirer un champ.
  • IWI propose les 76 colonnes de la trame. Une colonne exigee encore vide indique en rouge le nombre de valeurs manquantes. Le fichier part quand meme.
  • Le format (.xlsx, .csv ou .zip) se choisit a cote du bouton Exporter. Le fichier tient sur un seul onglet.

Administration

Le menu Administration n’apparait que si votre role peut ouvrir au moins un module (attributs, groupes, categories, roles, conditions, preferences). La pagination de la liste et le seuil de completion se reglent dans les preferences de l’application. Le theme d’affichage, lui, est personnel.

Creer un attribut, un groupe ou une categorie est reserve aux roles qui ont ce droit. Sinon, demandez-le a Alexis Béranger. Un attribut systeme se consulte, il ne se modifie pas. Quitter l’edition d’un attribut sans enregistrer demande une confirmation.

Un fournisseur se cree avec un code, un nom, et un trigramme facultatif. La liste des conditions montre le nom, le code et le trigramme. Il n’y a pas de commentaire. L’historique d’une ligne est dans Modifier, et il s’ecrit a l’enregistrement.

Les alertes se reglent dans Administration. Une alerte compare un attribut numerique a un seuil, en dessous ou au-dessus. Le taux de marque est alerte en dessous de 20 %. Creer ou supprimer une alerte demande ce droit. Sinon, demandez-le a Alexis Béranger.
