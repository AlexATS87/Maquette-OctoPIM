Fonction d’export

Extraire une trame du catalogue. L’utilisateur coche les groupes et les champs. Un groupe decoche retire ses champs. Un champ present dans deux groupes part des qu’un de ces groupes reste coche. Le fichier peut tenir sur un seul onglet et se telecharger en zip. La trame IWI ne part que si ses colonnes exigees sont remplies.

Qu’est-ce que l’export ?

Un fichier .xlsx dont les colonnes portent l’identifiant d’attribut (pas le libelle, trop instable pour un echange). Le perimetre reprend les filtres de la liste (categorie, recherche, selection).

A quoi ça sert ?

  • Donner un extrait de travail (acheteur, agence, controle qualite).
  • Produire une trame reimportable (memes identifiants qu’a l’import).
  • Pont transitoire vers Snowflake / autres outils tant que les interfaces ne sont pas en place.

Comment ça marche

  • Choisir une trame (Catalogue, IWI, ou une trame enregistree).
  • Cocher les groupes et, dans chaque groupe, les champs.
  • Option : un seul onglet, ou un onglet par groupe.
  • Option : fichier zip contenant le classeur.
  • IWI : le telechargement est refuse tant qu’une colonne exigee est vide. Le decompte des manques s’affiche avant.
Regles RG-EXP-01 — Les en-tetes d’export sont les identifiants d’attribut.
RG-EXP-02 — Le perimetre = filtres liste + selection eventuelle.
RG-EXP-03 — Seuls les produits des categories en lecture sont exportes.
RG-EXP-04 — L’export IWI ne se telecharge que si chaque colonne exigee par IWI est remplie. L’utilisateur voit le decompte des manques avant.
RG-EXP-05 — Prix 2 IWI = prix catalogue. Prix 1 IWI = PA ATS. Le distributeur est fixe (ATS, Audioptic Trade Services).
RG-EXP-06 — Decocher un groupe decoche ses attributs. Un attribut dans deux groupes est exporte si au moins un de ces groupes reste coche.
RG-EXP-07 — Une trame enregistree memorise les groupes, les champs, l’onglet unique et le zip.
Cible Job serveur, historisation des exports, formats vers Cosium / Osmose a specifier.
