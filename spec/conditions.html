Conditions commerciales

Une condition commerciale n’est pas un attribut duplique : c’est une ligne d’accord marque × fournisseur × type de produit × segmentation (ex. Optique / Solaire), avec RF, RFA, remises, reprise, livraison.

Qu’est-ce qu’une condition commerciale ?

C’est le barème négocié avec un fournisseur pour une marque, dans une famille et une segmentation. Sur la fiche produit, ces valeurs se retrouvent dans l’onglet Conditions commerciales lorsque la marque et le fournisseur correspondent.

A quoi ça sert ?

  • Centraliser RF, RFA, remise interne, reprise échange, conditions de livraison.
  • Eviter de resaisir le barème sur chaque produit.
  • Alimenter les calculs de tarif (PA interne, etc.).

  • Maquette Boutons + Fournisseur et + Nouvelle condition commerciale.
  • La liste des marques est unique et s’enrichit quand on saisit une nouvelle marque (produit ou condition).
  • Les pourcentages s’affichent en % (stockage decimal 0–1).
  • Le fournisseur a un code et un trigramme. Le trigramme est facultatif a la creation (3 caracteres). Les fournisseurs deja en base le recoivent depuis la colonne Fab. du fichier d’associations, quand une de leurs marques y figure. Sans marque dans ce fichier : APLUS, BLI-DBP, GRASSET, L’AMY, COMO SAS, ODLM, OPAL, SEAPORT, CCO. MARCHON est MAF. Karl Lagerfeld a aussi une ligne ATS : le trigramme du fournisseur reste celui partage par les autres marques Marchon.
  • La liste affiche le nom du fournisseur, son code et son trigramme. Il n’y a pas de commentaire sur l’accord.
  • L’historique de la ligne est dans le formulaire de modification. Il s’ecrit a l’enregistrement : date, utilisateur, champ, ancienne valeur, nouvelle valeur.

En detail

Une condition commerciale est un accord : une marque, un fournisseur, un type de produit et une segmentation. Une seule ligne pour cette combinaison. Quand la fiche a la meme marque et le meme fournisseur, la remise interne, le RF et la RFA de la ligne sont reportes, sans ressaisie. La remise interne compte dans la completion. Le panneau de la fiche montre aussi le code et le trigramme.

  • La marque est un referentiel unique. Une valeur nouvelle, saisie ici ou sur une fiche, l’enrichit. Sur une lentille, la marque se saisit dans Caracteristiques lentille : c’est le meme attribut.
  • Le fournisseur a un nom, un code et un trigramme facultatif de 3 caracteres. Le trigramme s’initialise depuis la colonne Fab. des associations IWI quand une marque du fournisseur y figure. La liste montre les trois. Pas de commentaire sur l’accord. L’historique de la ligne est dans Modifier, ecrit a l’enregistrement.
  • Un fournisseur sans accord reste choisissable. Les remises restent vides tant qu’il n’y a pas de ligne. PACIFIC, TRADECON et CLASSICPACKING sont dans le referentiel accessoire, sans accord et sans trigramme.
  • Les pourcentages s’affichent en % et se stockent entre 0 et 1. Le PA opticien et la marge interne lisent le RF et la RFA de l’accord, pas un champ de tarification separe.
Regles RG-CC-01 — Une ligne d’accord est unique pour la combinaison marque × fournisseur × type × segmentation.
RG-CC-02 — Marque n’est pas une liste figee : toute nouvelle valeur enrichit le referentiel.
RG-CC-03 — Quand un produit a une marque et un fournisseur qui matchent une ligne d’accord, la remise interne, le RF et la RFA de cette ligne sont reportes sur la fiche. La remise interne compte dans la completion.
RG-CC-04 — Le trigramme du fournisseur est facultatif. Il est initialise depuis la colonne Fab. des associations IWI lorsqu’une marque de ce fournisseur y est presente. Sinon il reste vide. La liste montre le nom, le code et le trigramme.
RG-CC-05 — Pas de commentaire sur une condition commerciale. L’historique de la ligne s’ecrit a l’enregistrement, dans le formulaire : date, utilisateur, champ, ancienne et nouvelle valeur.
RG-CC-06 — Un fournisseur sans ligne d’accord reste choisissable sur la fiche. Les remises ne s’affichent qu’une fois une ligne marque × fournisseur existe. PACIFIC, TRADECON et CLASSICPACKING sont dans le referentiel, sans accord et sans trigramme.
