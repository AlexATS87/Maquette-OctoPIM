Sommaire — specifications OctoPIM

Ce dossier HTML est la spec vivante du projet. Elle se lit dans le navigateur (http://127.0.0.1:8767/spec/) et se colle dans Confluence via le bouton en haut a droite (titres, tableaux, images et schemas).

Maquette vs cible Chaque page distingue le comportement deja visible dans la maquette (Maquette) de ce qui doit etre construit (Cible). Sans ce tag, un placeholder de la maquette peut etre pris pour une exigence.

Comment coller dans Confluence

  1. Ouvrir la page dans le navigateur.
  2. Cliquer sur Copier pour Confluence (les captures sont embarquees).
  3. Dans Confluence, editer la page cible et coller (Ctrl+V).
  4. Les schemas SVG se collent comme images ; le bloc Mermaid replie sert si l’espace a la macro Mermaid.

Principes transverses

  • Le PIM doit rester parametrable : attributs, groupes, categories et colonnes de liste se configurent sans redeploiement.
  • Un identifiant d’attribut sert a l’import, l’export et les formules — on le nomme « identifiant » dans cette spec, pas par son nom interne.
  • Les visuels, schemas et regles vivent dans la meme section que l’explication (pourquoi / comment).
